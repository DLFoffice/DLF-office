# เว็บไซต์มูลนิธิการศึกษาทางไกลผ่านดาวเทียม ในพระบรมราชูปถัมภ์ (เชื่อมต่อ Supabase)

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าเว็บหลัก (ดึงข้อมูลจาก Supabase) |
| admin.html | ระบบจัดการหลังบ้าน: เข้าสู่ระบบ, แก้ไขข้อมูล, อัปโหลดรูป/ไฟล์ |
| config.js | ใส่ Project URL และ anon key ของ Supabase |
| supabase-setup.sql | สคริปต์สร้างตาราง สิทธิ์ และ Storage bucket |
| data.js | ข้อมูลตั้งต้น และใช้เป็นข้อมูลสำรองหาก Supabase ใช้งานไม่ได้ |

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)
1. สร้างโปรเจกต์ที่ https://supabase.com (เลือก Region: Singapore เพื่อความเร็วในไทย)
2. ไปที่ **SQL Editor** → วางเนื้อหา `supabase-setup.sql`
   - แก้ `admin@example.com` ท้ายไฟล์เป็นอีเมลผู้ดูแลจริง (เพิ่มได้หลายบรรทัด) → กด Run
3. ไปที่ **Authentication → Users → Add user** สร้างบัญชีด้วยอีเมลเดียวกัน พร้อมรหัสผ่าน
   (ติ๊ก Auto Confirm User)
4. ไปที่ **Authentication → Sign In / Providers** ปิด "Allow new users to sign up"
   เพื่อไม่ให้บุคคลภายนอกสมัครเอง
5. ไปที่ **Project Settings → API** คัดลอก Project URL และ anon public key ไปใส่ใน `config.js`
   (ห้ามใช้ service_role key)
6. อัปโหลดไฟล์ทั้งหมดขึ้นโฮสติ้ง แล้วเปิด `admin.html` → เข้าสู่ระบบ → กด **บันทึกขึ้นเว็บ**
   ครั้งแรกเพื่อสร้างข้อมูลชุดแรก

## การใช้งานประจำวัน
- เปิด `admin.html` → เข้าสู่ระบบ
- แก้ไขข้อความ / เพิ่ม / ลบ / เลื่อนลำดับรายการ
- ช่องรูปภาพ: กด **อัปโหลดรูป** (รูปใหญ่จะถูกย่อให้กว้างไม่เกิน 1920px อัตโนมัติ)
- ช่องลิงก์ของประกาศ / เอกสาร / ข่าว: กด **อัปโหลดไฟล์** เพื่อแนบ PDF, Word, Excel ฯลฯ (ไม่เกิน 50MB)
- กด **ดูตัวอย่าง** → ตรวจสอบ → กด **บันทึกขึ้นเว็บ** (หน้าเว็บเปลี่ยนทันที)
- กด **สำรองข้อมูล** เป็นระยะ เพื่อเก็บไฟล์สำรองไว้ในเครื่อง

## ไฟล์ที่อัปโหลดเก็บที่ไหน
Supabase → Storage → bucket `media` แยกโฟลเดอร์ตามส่วนของเว็บและวันที่ เช่น `news/2026-11-25/...jpg`

## สถิติผู้เข้าชม
นับจริงอัตโนมัติ (นับ 1 ครั้งต่อการเปิดเบราว์เซอร์ 1 รอบ ตามเวลาประเทศไทย)
ใส่ยอดสะสมจากเว็บเดิมได้ที่ช่อง "ยอดสะสมจากเว็บเดิม" ในหมวดสถิติ
ถ้าต้องการใส่ตัวเลขเอง ให้เอาเครื่องหมายถูกในช่อง "นับผู้เข้าชมจริงอัตโนมัติ" ออก

## ความปลอดภัย
- ทุกคนอ่านข้อมูลเว็บได้ แต่แก้ไขหรืออัปโหลดได้เฉพาะอีเมลที่อยู่ในตาราง `admins` และล็อกอินแล้ว (บังคับด้วย RLS)
- เพิ่มผู้ดูแลใหม่: เพิ่มอีเมลในตาราง `admins` (Table Editor) และสร้าง user ใน Authentication
